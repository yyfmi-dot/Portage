# Portage UX v0.2

用户从原生 session 出发，在一个工作台直接对话、组成房间和追踪信息流。交互原型为 demos/portage-ux-demo.html，所有 session、消息和投递均为模拟。

## 信息架构

| 区域 | 内容与操作 |
| --- | --- |
| 左侧来源树 | Provider → App / VS Code CLI / Terminal → Session，搜索、选择、开关和拖入房间 |
| 左侧房间列表 | 房间名称、成员数、暂停状态，新建与进入 |
| 中央主区 | 房间、对话、信息流三种视图，共用 session / room 选择 |
| 右侧检查器 | 成员、消息、链路的来源、权限、队列、规则版本与产物 |
| 输入区 | 实际目标、主题、正文、附件及发送 |
| 活动区 | 消息和状态事件，点击定位对应对象 |

真实产品首先展示已发现 session，恢复最近使用位置。原型打开一个已配置示例房间，便于演示完整场景。

## 来源树与房间

```text
Codex
  App
    产品讨论
  VS Code CLI
    适配器实现
  Terminal
    统筹 · session 1
Claude
  App
    资料会话
  VS Code CLI
    界面评审
  Terminal
    代码审查
```

每项显示名称、入口、状态与队列数量。选择 session 可直接对话。通信开关控制跨 session 收发和自动唤醒。

拖入已有房间添加成员，多选可形成新房间。“添加成员”提供相同的键盘和触屏入口。session 可以属于多个房间，来源树保留一个原始身份。

## 房间视图

采用固定工位布局，成员有明确名称、角色、原生入口和文字状态。工作、未唤醒、排队、关闭和预算等待具有各自视觉反馈。位置保持稳定，动画表达实际事件。

顶部提供唤醒方式、暂停自动通信、添加成员、collaboration.md。选中成员时，右侧展示执行、连接、队列、通信开关和规则版本。

成员之间的消息流可以切换到精确信息流视图。视图共用事件，房间内消息可以定位对应链路和原生凭据。

## 对话与记录

选择 session 时显示实际原生入口及能力，选择房间时显示成员和唤醒范围。Thread 用主题标签表示。

消息显示来源、目标、时间、附件、修订关系和每位接收方状态。点开回执查看等待原因、投递尝试及原生证明。

记录 CRUD 显示本地与原生的实际作用范围。已投递消息修订保留历史版本，原生更正按 capability 执行。创建、归档、终止进程和删除原生历史分别说明效果。

## 信息流监控

节点为用户、session、房间或 artifact。边表达发送、转发、回复和引用，运动粒子表达传递，已完成链路保留细线。

点击链路后显示 messageId、traceId、因果引用、规则版本、正文、附件、每次尝试和原生凭据。推断关系使用虚线与 inferred 文本。

支持房间、thread、成员、时间与状态过滤，暂停动画和历史回放。回放清楚显示历史时间，实时事件持续保存。

## 状态

| 文字状态 | 含义 | 操作 |
| --- | --- | --- |
| 工作中 | 宿主报告 running | 看进度或排队发送 |
| 未唤醒 | 可读但未被唤醒 | 唤醒一次 |
| 等待投递 | 有待投递消息 | 查看 busy / 离线 / 预算等原因 |
| 待你处理 | 原生等待用户 | 打开原生入口 |
| 通信关闭 | 收发与自动唤醒已关闭 | 打开通信 |
| 预算等待 | 通信预算达到限制 | 查看用量、调整、恢复 |
| 只读连接 | 当前入口提供读取能力 | 查看历史和其他入口 |
| 状态未知 | 信号缺失或过期 | 检查连接 |

颜色辅助文字。工作使用暖橙，可用与成功使用绿色，选中与等待使用蓝色，未唤醒与离线使用灰色。失败单独标记。

## MD 编辑与生效

规则面板切换全局、工作区、房间和成员，显示范围、正文、结构化策略和 revision。

保存 draft，校验后发布。正文用于下一次 query，服务端权限和预算用于下一次检查。忙碌成员显示待下一轮应用。原生宿主要求重载时显示待原生重载及原因。

用户可以预览实际 query 的 MD 层级、版本、内容体积和附件转换。原始消息保持独立。

## 沟通预算

mentions、coordinator、all、manual 明确谁能看和谁会被唤醒。面板展示自动唤醒次数、轮次、消息速率和活跃席位。

预算命中后显示原因与阈值。暂停、恢复、唤醒一次和配置编辑可直接完成。表单与 MD frontmatter 编辑同一份版本化规则。

## 原型范围

原型提供来源分组、房间、成员拖入与选择添加、直接聊天、房间消息、附件引用、唤醒方式、通信开关、暂停 / 恢复、MD 编辑发布、队列原因、信息流与检查器。

演示协作按钮生成明确标记的模拟 agent 回复。原型刷新恢复数据，原生 session 的实际增删改查与同步通过未来适配器实现。

## 可访问性与性能

关键操作有文字和键盘入口。Canvas 图中的成员在 DOM 中有可聚焦卡片，链路有对应事件列表。支持 reduced-motion 和动画暂停。

窄屏检查器折叠，输入始终可用。真实实现对长历史虚拟化、增量订阅和图谱聚合，页面隐藏时停绘。
